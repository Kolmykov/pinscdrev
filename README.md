# Пинскдрев

Статичный сайт-прототип интернет-магазина мебели из массива (редизайн pandrev.ru). Только десктоп.

- `index.html`, `catalog.html`, `cart.html` — страницы
- `css/site.css` — собранные стили, `css/site.src.css` — исходник
- `js/site.js` — каталог, корзина, избранное, фильтры
- `_build/build.py` — генератор страниц и `site.css` (`python3 _build/build.py`)

Просмотр: `python3 -m http.server`, затем http://localhost:8000
