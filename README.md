# Пинскдрев

Статичный сайт-прототип интернет-магазина мебели из массива (редизайн pandrev.ru). Только десктоп.

- `index.html`, `catalog.html`, `cart.html` — страницы
- `css/site.css` — собранные стили, `css/site.src.css` — исходник
- `js/site.js` — каталог, корзина, избранное, фильтры
- `_build/build.py` — генератор страниц и `site.css` (`python3 _build/build.py`)

Просмотр: `python3 -m http.server`, затем http://localhost:8000

## Широкие экраны

Макет 1440. Все размеры в px переводятся сборкой в `calc(N * var(--u))`, где `--u = ширина окна / 1440` на окнах уже 1440 и `1` на всех остальных: сайт никогда не увеличивается (Vova: «овер увеличено»). На экранах шире 1440 содержимое (1320px) стоит по центру, фоновые фото и цветные полосы идут на всю ширину и просто обрезаются (cover). Не привязывать элементы к краю окна, только к контейнеру `.w` (надпись в футере: `left: calc(50% - 720px + 42px)`). При сборке проверять 1280, 1440, 1920 и 2560.
